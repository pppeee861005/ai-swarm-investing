📚 Dynamic Workflow 完全指南

🎯 核心概念

Dynamic Workflow（動態工作流）是 Claude Code Workflow 系統中的一種自驅動執行模式，允許工作流在執行過程中根據實時情況動態調整節奏和決策，而不是按預設的靜態計劃運行。

---
🔄 Static vs Dynamic 對比

❌ Static Workflow（靜態工作流）

// 固定的執行計劃，必須完成所有步驟
async function execute(context) {
  const step1 = await agent.run("Agent1");  // 必做
  const step2 = await agent.run("Agent2");  // 必做
  const step3 = await agent.run("Agent3");  // 必做
  return { success: true, output: step3 };
}

// 特點：
// ✗ 3個Agent必須全部執行
// ✗ 順序固定不變
// ✗ 無法根據中間結果調整

✅ Dynamic Workflow（動態工作流）

// 根據實時結果動態調整執行計劃
async function execute(context) {
  let results = [];

  // 根據預算動態調整執行次數
  while (budget.total && budget.remaining() > 50_000) {
    const result = await agent.run("DiscoveryAgent");
    results.push(...result.findings);

    log(`${results.length} 項發現，剩餘預算 ${Math.round(budget.remaining()/1000)}k`);

    // 如果找夠了，就停止
    if (results.length >= 10) break;
  }

  return { success: true, output: results };
}

// 特點：
// ✓ Agent可執行多次或零次
// ✓ 執行次數根據結果動態決定
// ✓ 可根據預算、進度自動調整

🎬 Dynamic Workflow 的 3 種常見模式

模式 1：Loop-Until-Count（迴圈直到達成目標數量）

const bugs = []
while (bugs.length < 10) {  // 動態條件
  const result = await agent("找出代碼中的 bug", {
    schema: BUGS_SCHEMA
  })
  bugs.push(...result.bugs)
  log(`${bugs.length}/10 已發現`)
}
return { confirmed: bugs }

應用場景：
- 🐞 持續發現bug，直到找到10個
- 🔍 逐輪進行代碼審查
- ✅ 質量關卡達成時停止

模式 2：Loop-Until-Budget（迴圈直到用完預算）

const findings = []
while (budget.total && budget.remaining() > 50_000) {  // 預算驅動
  const result = await agent("進行安全審計", {
    schema: FINDINGS_SCHEMA
  })
  findings.push(...result.findings)
  log(`${findings.length} 個發現，預算剩餘 ${Math.round(budget.remaining()/1000)}k`)
}
return { findings }

應用場景：
- 💰 用戶設置 +500k Token 預算
- 🔎 工作流自動擴展搜索範圍
- ⏹️ 用完預算時自動停止

模式 3：Loop-Until-Dry（迴圈直到沒有新發現）

const confirmed = []
let dryRounds = 0  // 連續無新發現的輪次

while (dryRounds < 2) {  // 2輪無新發現則停止
  // 並行執行多個Finder Agent
  const found = (await parallel(FINDERS.map(f => () =>
    agent(f.prompt, { schema: BUGS })
  ))).filter(Boolean).flatMap(r => r.bugs)

  // 去重：只保留新發現
  const fresh = found.filter(b => !seen.has(key(b)))

  if (!fresh.length) {
    dryRounds++  // 無新發現，計數器+1
    continue
  }

  dryRounds = 0  // 有新發現，重置計數器
  fresh.forEach(b => seen.add(key(b)))
  confirmed.push(...fresh)

  log(`第${dryRounds}輪：新增 ${fresh.length} 項`)
}

return { confirmed }

應用場景：
- 🔄 持續迭代搜索，直到沒有新發現
- 📊 用於全面審計、完整性檢查
- ⚡ 自適應停止，不浪費資源

💡 何時使用 Dynamic Workflow？

✅ 適合使用：
- 發現類任務（Bug、漏洞、改進點數量未知）
