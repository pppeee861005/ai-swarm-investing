# 📊 三維獵殺：多角度投資決策驗證系統

**核心目標**：在買入股票前，用**三個維度**（財務面、技術面、市場面）驗證，降低決策風險

**適用場景**：
- 想買某支股票，但想多角度驗證
- 想要「多維度確認」才敢下單
- 想建立系統化的買點驗證流程

**預期成果**：
- 生成完整的「三維驗證報告」
- 給出「買入信號強度」（弱 / 中等 / 強）
- 推薦「建議買入價位」和「風險評級」

---

## 第一章：問題定義

### 🎯 問題陳述

投資決策往往單一視角：看技術面就買，或看財務數據就買。但實際上，**一個高質量的買點應該是「多維度確認」的結果**。

**你遇到的問題**：
```
場景 1：股票技術面很好看（突破頸線，成交量爆發）
        但財務面呢？負債太高？

場景 2：財務數據很漂亮（PE低、ROE高）
        但股價是不是已經炒到位了？

場景 3：市場情緒很熱（大家都在買，新聞都是利好）
        但這是最後的「慶祝漲停」還是「新上升趨勢」？

➜ 你需要一個系統，同時檢查三個維度，只有「三個信號都合理」時才出手
```

### 📋 三個維度詳解

#### **維度 1：財務面**
檢查股票的「基本面健康度」

**需要看的指標**：
- **估值指標**：PE（市盈率）、PB（市淨率）、PS（市銷率）
  - PE < 行業平均 → 相對便宜
  - PB > 2.0 → 可能高估

- **盈利質量**：ROE（股東報酬率）、淨利率、毛利率
  - ROE > 15% → 盈利能力強
  - 淨利率 > 10% → 業務模式好

- **財務穩健**：負債率、流動比率、現金流
  - 負債率 < 60% → 財務槓桿合理
  - 經營現金流 > 淨利潤 → 盈利真實

**判斷邏輯**：
```
如果 (PE < 行業平均) AND (ROE > 15%) AND (負債率 < 60%)
  → 財務面信號：強
否則如果 (PE < 行業平均 * 1.2) AND (ROE > 12%)
  → 財務面信號：中
否則
  → 財務面信號：弱
```

#### **維度 2：技術面**
檢查股票的「走勢動量」

**需要看的指標**：
- **趨勢**：50日均線 vs 200日均線，股價在哪
  - 股價 > 50日 > 200日 → 強上升趨勢
  - 股價 < 50日 < 200日 → 強下降趨勢

- **動量**：成交量、動量指標（RSI、MACD）
  - 突破時成交量爆發 → 機構在進場
  - RSI > 50 且上升 → 動量在轉強

- **支撐與阻力**：歷史高低點、整數關口
  - 股價在大支撐位上方 → 有安全邊際
  - 即將突破關鍵阻力位 → 上升潛力大

**判斷邏輯**：
```
如果 (股價 > 50均 > 200均) AND (成交量 > 20日平均) AND (RSI > 50)
  → 技術面信號：強
否則如果 (股價 > 200均) AND (RSI > 40)
  → 技術面信號：中
否則
  → 技術面信號：弱
```

#### **維度 3：市場面**
檢查股票的「大環境」

**需要看的指標**：
- **行業景氣**：行業整體趨勢、競爭格局、政策風向
  - 所在行業在風口 → 有尾風
  - 行業龍頭在上漲 → 這支是跟隨還是領先

- **市場情緒**：大盤走勢、融資餘額、機構活動
  - 大盤在上升趨勢 → 個股容易被帶動
  - 融資餘額在高位 → 風險提示

- **新聞與事件**：最近有沒有重大利好/利空
  - 「利好已充分反映」還是「利好才剛開始」
  - 「短期炒作」還是「長期趨勢」

**判斷邏輯**：
```
如果 (行業景氣指數 > 60) AND (大盤 > 200均) AND (融資餘額 < 歷史高位 * 80%)
  → 市場面信號：強
否則如果 (行業景氣指數 > 50) AND (大盤 > 250日均)
  → 市場面信號：中
否則
  → 市場面信號：弱
```

4. **人為判斷**：系統給信號，最終決策還是由你做

## 第二章：驗證標準

### ✅ 成功標準（驗證的質量）

| 指標 | 標準 | 檢驗方法 |
|------|------|--------|
| **財務數據完整性** | 能獲取PE、PB、ROE、負債率 | 檢查數據源是否完整 |
| **技術指標準確性** | 週K、日K、成交量數據一致 | 與行情軟體對比 |
| **市場信息及時性** | 大盤走勢、融資數據在1日內 | 檢查時間戳 |
| **三維信號有效性** | 每個維度都有清晰的「強/中/弱」判斷 | 邏輯檢查，有無遺漏 |
| **報告可用性** | 報告清晰，可直接用於決策 | 閱讀報告，能否明確做決定 |

### 🎯 驗證的目標結果

**好的驗證應該是**：
```
✅ 三個維度都強 → 「強買入信號」（成功率最高）

⚠️ 兩個維度強 → 「中等買入信號」（可以買，但要控制倉位）

❌ 一個或零個維度強 → 「弱買入信號」（不建議買，等待機會）
```

### ❌ 系統的局限

1. **不會預測股票漲跌**

2. **不會消除所有風險**
   - 再好的買點也可能被黑天鵝打臉

3. **不會替代你的決策**
   - 系統給信號，你做決策
   - 你可以信任系統，也可以選擇違背系統

## 第四章：決策規則

### 📋 核心決策規則（5 個）

#### **規則 1：三維信號評分**

```
財務面評分 = (指標1 + 指標2 + 指標3) / 3
  其中：
  - PE < 行業均值 → +30 分
  - ROE > 15% → +35 分
  - 負債率 < 60% → +35 分

技術面評分 = (指標1 + 指標2 + 指標3) / 3
  其中：
  - 股價 > 50均 > 200均 → +30 分
  - 成交量突破 → +35 分
  - RSI > 50 且上升 → +35 分

市場面評分 = (指標1 + 指標2 + 指標3) / 3
  其中：
  - 行業景氣指數 > 60 → +30 分
  - 大盤走勢強 → +35 分
  - 融資餘額健康 → +35 分
```

#### **規則 2：綜合買入信號**

```
綜合評分 = (財務面評分 + 技術面評分 + 市場面評分) / 3

如果 綜合評分 >= 75
  → 買入信號：強 ✅

否則如果 綜合評分 >= 55
  → 買入信號：中 ⚠️

否則
  → 買入信號：弱 ❌
```

#### **規則 3：風險評級**

```
風險評級 的計算基於：
1. 負債率（越高越危險）
2. 估值高度（PE越高越危險）
3. 大盤風險（市場情緒越瘋狂越危險）

如果 (負債率 < 40%) AND (PE < 行業均值) AND (融資餘額 < 歷史高位 * 60%)
  → 風險級別：🟢 低

否則如果 (負債率 < 60%) AND (PE < 行業均值 * 1.2) AND (融資餘額 < 歷史高位 * 80%)
  → 風險級別：🟡 中

否則
  → 風險級別：🔴 高
```

#### **規則 4：建議給出**

```
如果 (買入信號 = 強) AND (風險級別 = 🟢 低)
  → 推薦：可以買入，這是你等著的機會

否則如果 (買入信號 = 強) AND (風險級別 = 🟡 中)
  → 推薦：可以買入，但控制倉位，建議分批進入

否則如果 (買入信號 = 強) AND (風險級別 = 🔴 高)
  → 推薦：信號不錯，但市場風險大，建議等市場回調後再買

否則如果 買入信號 = 中
  → 推薦：可以買入，但不是最佳時機，如果有更好的機會不用強行買這個

否則
  → 推薦：現在不是好時機，等待
```

#### **規則 5：買入價位調整**

```
基於當前價格和估值，給出「安全買入區間」

建議買入價位 = 公允價值 × (1 - 安全邊際%)

其中安全邊際% 的計算：
- 風險級別 = 🟢 低 → 安全邊際 = 5%-10%
- 風險級別 = 🟡 中 → 安全邊際 = 10%-20%
- 風險級別 = 🔴 高 → 安全邊際 = 20%-30%
```

### 🔄 降級與升級條件

#### 降級條件（如果遇到這些，警惕）

1. **降級 Level 1：突發利空**
   - 如果在驗證過程中，出現重大利空（如監管風險、財務造假爆料）
   - 立即將買入信號降級一檔（強→中，中→弱）

2. **降級 Level 2：數據不足**
   - 如果某個維度的數據不足（比如財務報表未公布），無法給出信號
   - 暫停驗證，等待數據完整

3. **降級 Level 3：市場急轉**
   - 如果在驗證的過程中，大盤出現 -5% 以上的跌幅
   - 重新評估市場面的信號，可能整體信號會下調

#### 升級條件（如果遇到這些，確認買入）

1. **升級 Level 1：多個機構入場**
   - 如果看到多家機構在這支股票增倉（從F10基金持倉數據可見）
   - 說明專業機構也看好，可以增加信心

2. **升級 Level 2：突發利好**
   - 如果在驗證過程中，出現重大利好（新產品、新合作、業績超預期）
   - 可以將買入信號升級一檔（弱→中，中→強）

3. **升級 Level 3：同行對比**
   - 如果這支股票對比同行龍頭，各指標都更好
   - 說明有被低估的機會，升級信心

## 第七章：自定義與應用

### 🎯 你可以自行修改的部分

1. **調整三個維度的權重**
   - 默認：財務面 33% + 技術面 33% + 市場面 34%
   - 你可以改成：財務面 50% + 技術面 30% + 市場面 20%（如果你特別看重基本面）

2. **調整評分的閾值**
   - 默認：PE < 行業均值 才給滿分
   - 你可以改成：PE < 行業均值 * 1.2（更寬鬆）或 < 行業均值 * 0.8（更嚴格）

3. **添加你關心的指標**
   - 默認只看 PE、ROE、負債率
   - 你可以加：現金流、股息率、應收賬款周期（如果你特別關心現金流）

4. **調整買入決策標準**
   - 默認：強信號 + 低風險 = 推薦買入
   - 你可以改成：強信號 就買（激進），或只有 強信號 + 低風險 + 大盤強勢 才買（保守）

### 🔧 怎麼用 Claude Code 來做這個驗證？

**第 1 步**：複製這份定義書

**第 2 步**：修改你關心的部分（如果需要的話）

**第 3 步**：告訴 Claude Code：
```
我想驗證股票 XXXXX
使用「三維獵殺」定義書
關注的股票代碼：XXXXX
我打算買的價位：XXX 元
特別敏感的風險：[你的風險偏好]
```

**第 4 步**：Claude Code 會：
- 搜集三個維度的數據
- 按照規則進行評分
- 生成完整報告
- 給你「買 / 不買」的建議

**第 5 步**：你決策
- 可以信任系統的建議買入
- 也可以自己加一些條件（比如「等大盤漲到 3500 才買」）

## 核心提醒

> **三維獵殺的本質不是「預測」，而是「驗證」。**
>
> 我們不會告訴你「這支股票一定會漲」。
>
> 我們會告訴你「基於當前信息，這支股票的買點質量如何」。
>
> 好的買點 ≠ 一定會漲，
> 但 壞的買點 容易被套。
>
> 我們用系統降低買壞的概率，不是提高買好的概率。
