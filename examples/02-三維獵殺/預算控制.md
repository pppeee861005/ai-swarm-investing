# 💰 三維獵殺：成本監控與預算控制書

**核心目的**：通過實時成本監控，確保「三維獵殺」驗證流程在預算內完成，同時保持驗證質量

**適用讀者**：
- 使用「三維獵殺」定義書進行股票驗證的用戶
- 想了解 AI 驗證實際成本的人
- 想優化成本效率的投資決策者

---

## 第一章：預算概況

### 💡 成本單位轉換（重要提示）

**1 單位 = 100 萬 Token**

本驗證的預算轉換：
- **總預算**：0.25 單位 = 250 萬 Token ≈ $1.5-6 美金
- **預期成本**：0.10 單位 = 100 萬 Token ≈ $0.8-2.5 美金
- **應急預留**：0.15 單位 = 150 萬 Token ≈ $0.7-3.5 美金

### 📊 預算三元素

| 元素 | 用途 | 分配 | 說明 |
|------|------|------|------|
| **預期成本** | 正常流程消耗 | 0.10 | 順利完成驗證的估計成本 |
| **應急預留** | 應對變化 | 0.15 | 遇到複雜情況的預留金 |
| **總預算** | 絕對上限 | 0.25 | 不能超過的紅線 |

### 💭 為什麼要留這麼多預留？

**三個原因**：

1. **數據搜集的複雜性**
   - 不是每家公司的財務數據都輕鬆取得
   - 有時需要跨多個數據源對比驗證
   - 有時需要處理異常數據（如停牌、除權等）

2. **技術指標的計算複雜性**
   - 需要下載足夠長時間的K線數據（至少2年）
   - 需要計算多條均線、動量指標
   - 有時需要進行複雜的圖形分析（支撐位、阻力位）

3. **市場信息的動態性**
   - 市場每天變化，需要實時更新數據
   - 有時出現突發情況需要重新評估
   - 有時需要查閱過往新聞、事件驗證

**結論**：預留 60% 是合理的，確保質量不打折扣

## 第二章：成本分解

### 📈 詳細成本構成

#### 環節 1：數據搜集與驗證（0.03 單位 = 30 萬 Token）

|-------|------|------|
| 搜集財務數據 | 0.01 | 查詢最新季度報表、年度報告，獲取所需指標 |
| 搜集技術數據 | 0.01 | 下載 2 年的 K 線、計算均線、成交量 |
| 搜集市場數據 | 0.01 | 查詢行業信息、大盤走勢、融資數據、新聞事件 |

**質量檢查**：確保三個數據源都完整，無重大遺漏

#### 環節 2：財務面分析（0.02 單位 = 20 萬 Token）

| 子任務 | 成本 | 內容 |
|-------|------|------|

| 計算盈利質量 | 0.005 | ROE、淨利率、毛利率的計算 |
| 評估財務穩健 | 0.005 | 負債率、流動比率、現金流分析 |

**質量檢查**：所有計算邏輯清晰，無計算錯誤

#### 環節 3：技術面分析（0.02 單位 = 20 萬 Token）

| 子任務 | 成本 | 內容 |
|-------|------|------|

| 支撐阻力 | 0.005 | 歷史高低點、整數關口分析 |

**質量檢查**：圖形描述清晰，轉折點標記正確

#### 環節 4：市場面分析（0.02 單位 = 20 萬 Token）

| 子任務 | 成本 | 內容 |

**質量檢查**：判斷合理，邏輯連貫

| 內容優化與校對 | 0.002 | 邏輯檢查、表述優化、避免遺漏 |

**質量檢查**：報告可讀性強，結論清晰

## 第三章：成本監控策略

### 📊 四階段監控機制

每個驗證流程分成 4 個檢查點，實時監控成本和進度。

#### 檢查點 1：數據搜集完成（預期時間：5 分鐘）

```
目標成本：0.03 單位 = 30 萬 Token
進度：20%

關鍵檢查：
├─ ✅ 財務數據是否完整（至少最新 2-3 季度）
├─ ✅ 技術數據是否完整（至少 2 年 K 線）
└─ ✅ 市場數據是否最新（1 日內）

如果全部通過 → 進入下一階段 ✅
如果有任何不通過 → 返回搜集，追加 0.02 成本 ⚠️
```

**此階段實際消耗**：
- 順利情況：0.03
- 複雜情況（數據缺失、需要多輪查詢）：0.05

#### 檢查點 2：財務 + 技術面分析完成（預期時間：8 分鐘）

```
目標成本：0.08 單位 = 80 萬 Token（累計）
進度：40%

關鍵檢查：
├─ ✅ 財務面是否給出清晰評分
├─ ✅ 技術面是否給出清晰評分
└─ ✅ 兩個維度的邏輯是否有衝突

檢查邏輯例子：
如果財務面「強」但技術面「弱」
  → 可能意味著「公司好，但股價已經炒高了」
  → 需要額外評論：「等回調」還是「高位布局」

如果全部通過 → 進入下一階段 ✅
如果有邏輯問題 → 重新分析，追加 0.01-0.02 成本 ⚠️
```

**此階段實際消耗**：
- 順利情況：0.05
- 複雜情況：0.07

#### 檢查點 3：市場面分析完成（預期時間：12 分鐘）

```
目標成本：0.15 單位 = 150 萬 Token（累計）
進度：60%

關鍵檢查：
├─ ✅ 市場面是否給出清晰評分
├─ ✅ 三個維度是否形成完整圖景
└─ ✅ 是否發現重大風險信號

風險信號檢查清單：
□ 公司是否有造假嫌疑
□ 行業是否面臨政策打擊
□ 大盤是否在高位瘋狂
□ 融資是否在極端高位
□ 公司是否有退市風險

如果沒有紅色風險 → 進入報告階段 ✅
如果發現重大風險 → 調整評分，追加 0.02-0.03 成本 ⚠️

⚠️ 警告：此時已達預期成本，進入「成本監控高度警惕」狀態
```

**此階段實際消耗**：
- 順利情況：0.07
- 複雜情況：0.10

#### 檢查點 4：報告生成與最終檢查（預期時間：18 分鐘）

```
目標成本：0.22-0.25 單位 = 220-250 萬 Token（累計）
進度：88-100%

關鍵檢查：
├─ ✅ 綜合評分計算無誤
├─ ✅ 買入建議是否與評分相符
├─ ✅ 風險提示是否足夠全面
└─ ✅ 報告整體邏輯是否自洽

最終質量檢查清單：
□ 是否有邏輯漏洞
□ 是否有計算錯誤
□ 是否有數據衝突
□ 報告是否可直接用於決策

如果全部通過 → 輸出最終報告 ✅ 完成
如果有問題 → 修改，預留成本內完成 ⚠️

🔴 臨界：此時成本已達 80%+，只允許必要的修改
```

**此階段實際消耗**：
- 順利情況：0.03
- 小幅優化：0.05

## 第四章：降級與升級策略

### 📉 降級策略（遇到成本超支風險時）

#### 降級 Level 1：減少深度分析（節省 30% 成本）

**觸發條件**：成本達到預期值 0.10（進度 40% 左右）

**執行行動**：
- ✅ 保留：三個維度的基礎評分
- ✅ 保留：關鍵風險的識別
- ❌ 削減：細節比對、行業對標分析
- ❌ 削減：多層級情景分析

**實際例子**：
```
原計劃：詳細對比 A 股票 vs B 股票 vs 同行龍頭，共 3 層對比
降級後：只對比 A 股票 vs 行業平均值，共 1 層對比
節省：0.03 Token
```

**質量保證**：依然能給出清晰的「買 / 不買」建議，只是缺少精細分析

#### 降級 Level 2：停止低優先級分析（節省 50% 成本）

**觸發條件**：成本達到 85% 左右（進度 65% 以上）

**執行行動**：
- ✅ 保留：核心三維評分
- ✅ 保留：主要風險提示
- ❌ 停止：市場情緒深度分析
- ❌ 停止：複雜情景推演
- ❌ 停止：詳細建議區間計算

**實際例子**：
```
原計劃：計算「保守 / 中性 / 樂觀」三個估值情景，對應三個目標價
降級後：只給一個「合理目標價」
節省：0.02 Token
```

**質量保證**：報告依然有實用性，只是選項更少

#### 降級 Level 3：停止全部，輸出已有結果（節省 100% 成本）

**觸發條件**：成本達到 95% 或發現重大數據問題

**執行行動**：
- 立即停止驗證
- 輸出已計算的三維評分
- 給出基礎建議（買 / 觀望 / 不買）

**實際例子**：
```
情況：股票停牌，無法獲得最新技術數據
執行：跳過技術面深度分析，用最後一次完整數據給評分
結果：依然可以給出基礎建議，只是時效性打折
```

**質量保證**：基本可用，但可信度下降

### 📈 升級策略（發現信號強烈或風險重大時）

#### 升級 Level 1：深度風險分析（追加成本 0.02-0.03）

**觸發條件**：發現可能的風險信號（如負債率高、股價波動大）

**執行行動**：
- 追加：過往 5 年的歷史數據對比
- 追加：同行對標風險分析
- 追加：風險情景壓力測試

**實際例子**：
```
發現：公司負債率 70%，高於行業平均 55%
升級行動：
├─ 查詢過往 5 年負債率變化趨勢
├─ 對比同行負債率和償債能力
└─ 計算公司的債務風險評分

結果：更清晰的風險評估，幫助決策
```

**成本正當性**：風險識別不清楚會導致決策失誤，追加成本是值得的

#### 升級 Level 2：機會面研究（追加成本 0.01-0.02）

**觸發條件**：發現強買入信號且風險低

**執行行動**：
- 追加：行業成長空間分析
- 追加：公司競爭優勢評分
- 追加：3 年目標價推演

**實際例子**：
```
發現：財務 + 技術 + 市場三維都強，很少見的好機會
升級行動：
├─ 深度研究行業未來 3 年成長潛力
├─ 分析公司的核心競爭優勢是否可持續
└─ 推演 3 年目標價，計算上升潛力

結果：高度信心地把握機會
```

**成本正當性**：好機會難得，多花點 Token 做深度研究是划算的

#### 升級 Level 3：歷史對標研究（追加成本 0.02-0.04）

**觸發條件**：股票出現重大利好或進入關鍵轉折點

**執行行動**：
- 追加：查找歷史上類似股票的走勢案例
- 追加：對標分析（同類型公司當時怎麼走的）
- 追加：情景推演（樂觀 / 中性 / 悲觀）

**實際例子**：
```
發現：公司剛進入新業務賽道，是新的成長引擎
升級行動：
├─ 查找過往類似公司的案例
├─ 對標分析：X 公司進入新業務後股價漲了 200%
├─ 推演：這家公司如果成功，目標價可能是...

結果：有歷史參照的情景推演，增強決策信心
```

**成本正當性**：新情景需要更多數據支撐，追加投入是必要的

## 第六章：成本優化建議

### 🎯 如何逐步降低成本

#### 第一次驗證（成本參考：0.25）

由於不熟悉流程，會有額外探索成本。

#### 第二次驗證（成本參考：0.20）

了解了流程，某些環節會加快。建議：
- 複用上次的數據搜集經驗
- 快速識別關鍵數據源
- 減少驗證流程的重複檢查

#### 第三次驗證（成本參考：0.15-0.18）

開始掌握效率：
- 知道每家公司的常見數據源
- 能快速判斷數據質量
- 報告模板化程度提升

### 📊 成本與質量的 Tradeoff

| 預算級別 | 質量等級 | 適用場景 |
|---------|--------|--------|
| 0.10-0.15 | 基礎驗證 | 快速篩選、初步評估 |
| 0.15-0.25 | 標準驗證 | 一般投資決策 |
| 0.25-0.35 | 深度驗證 | 大額投資、關鍵決策 |
| 0.35+ | 超深度驗證 | 重點個股追蹤 |

### 💡 降低成本的訣竅

1. **提前準備**
   - 把想驗證的股票清單列出來
   - 預先了解行業背景
   - 減少驗證時的「探索」時間

2. **精準提問**
   - 而不是「幫我驗證這支股票」
   - 改為「幫我驗證這支股票，我特別關心現金流」
   - 更精準的需求 = 更少的無效計算

3. **定期更新而不是重複驗證**
   - 第一次完整驗證：0.25
   - 每月更新驗證：0.05-0.08（只更新關鍵數據）

4. **批量驗證**
   - 驗證 1 支股票：0.25
   - 驗證 3 支股票：0.60（比單獨驗證 3 次便宜）
   - 批量減少了重複的「系統初始化」成本

## 第七章：成本異常情況處理

### 🚨 如果成本超支怎麼辦？

#### 情況 1：某個環節比預期複雜（成本 +0.02-0.03）

**例子**：公司財務結構複雜，需要深度理解股權關係

**應對**：
```
選項 A：追加預算（從 0.25 升級到 0.28-0.30）
    適用：這支股票對你很重要，值得深入研究

選項 B：觸發降級，刪減低優先級分析
    適用：股票只是備選，不是必買

選項 C：暫停驗證，換個股票
    適用：還有其他更值得驗證的股票
```

#### 情況 2：驗證過程中發現重大新信息（成本 +0.03-0.05）

**例子**：發現公司有重大收購計劃、或監管調查等新聞

**應對**：
```
選項 A：繼續驗證，納入新信息
    成本追加 0.03-0.05
    結果：更完整的決策信息

選項 B：暫停驗證，等待事件進展
    節省成本 0.05-0.10
    結果：規避不確定性
```

#### 情況 3：市場快速變化（成本不確定）

**例子**：驗證過程中，大盤跌幅 -5%，市場面數據需重新評估

**應對**：
```
選項 A：重新驗證市場面，保持其他維度
    追加成本 0.02-0.03

選項 B：降級策略，給出基於舊市場面的預告報告
    成本 +0.01
    說明：「基於昨日數據，報告如下...建議待市場穩定後再決策」

選項 C：暫停驗證，待市場穩定
    成本 0，節省風險
```

## 第八章：成本與決策的關係

### 🎯 成本投入應該與決策重要度掛鉤

| 決策重要度 | 推薦成本 | 說明 |
|-----------|--------|------|
| **低** | 0.08-0.12 | 試驗性持倉、輔助倉位 |
| **中** | 0.15-0.20 | 正常選股、核心決策 |
| **高** | 0.25-0.35 | 大額投資、重點個股 |
| **極高** | 0.35+ | 集中投資、組合核心 |

### 💭 反思：值不值得花這個成本？

**好的問題**：
```
「這支股票我打算投入 10 萬元，值不值得花 $2-6 去深入驗證？」

答案：值得。10 萬 vs $2-6，成本比 1666:1
      少買幾只就能覆蓋驗證成本
```

**不好的問題**：
```
「我只是好奇，想看看某支股票怎麼樣」

答案：可以，但建議用基礎驗證 (0.08-0.10)
      而不是完整驗證 (0.25)
```
