## 🏆 按技術棧分類

### JavaScript/Node.js

所有項目都用 JavaScript，但技術棧不同：

**前端相關**
- ❌ 無（所有項目都是後端 Agent）

**數據處理**
- 蜂群覺醒：輕量級數據計算
- 三維獵殺：複雜統計計算（用 math.js）
- 末日推演：蒙特卡洛模擬（數值密集）

**API 集成**
- 新聞獵手：多源新聞 API 集成
- 跨境狙擊：多個交易所 API
- 終極顧問：Claude API 長上下文管理

**數據庫**
- 蜂群覺醒：✗ 無（內存計算）
- 三維獵殺：✗ 無（實時推理）
- 新聞獵手：✓ 需要 SQLite/PostgreSQL
- 末日推演：✓ 需要 MongoDB（模擬數據存儲）

## 🔧 按技術難度分類

### 🟢 初級（適合剛開始的人）

#### 蜂群覺醒
```javascript
class ScoutAgent {
  async monitor() {
    // 獲取股票數據
    // 檢查是否觸發告警
    // 返回結果
  }
}
```
- **難度原因**：邏輯清晰，三個簡單 Agent
- **技術**：基本的異步操作、Array.map()、Promise.all()
- **時間投入**：1-2 小時即可理解核心

---

### 🟡 中級（需要有一定基礎）

#### 三維獵殺
```javascript
async function evaluate(stock) {
  const [fundamental, technical, sentiment] = await Promise.all([
    analyzeFundamental(stock),
    analyzeTechnical(stock),
    analyzeSentiment(stock)
  ]);

  // 用 Claude 進行複雜推理
  return await callClaudeAPI({
    fundamental,
    technical,
    sentiment
  });
}
```
- **難度原因**：多維度分析、Claude API 調用
- **技術**：Promise 高級用法、API 集成、JSON 解析
- **時間投入**：3-4 小時理解邏輯 + API 集成

#### 自動校準
```javascript
function calculateRebalance(current, target) {
  // 計算偏差
  // 優化再平衡方案（考慮交易成本）
  // 返回行動建議
}
```
- **難度原因**：數學計算、優化算法
- **技術**：線性規劃、成本函數優化
- **時間投入**：2-3 小時理解算法

---

### 🔴 高級（需要深厚基礎）

#### 新聞獵手
```javascript
async function analyzeNews(articles) {
  // 爬取多個新聞源
  // NLP 情感分析
  // 相關性計算
  // 信號生成
}
```
- **難度原因**：多源數據整合、NLP、複雜流程
- **技術**：爬蟲、NLP 庫、數據清洗、流程管理
- **時間投入**：2-3 天

#### 跨境狙擊
```javascript
async function arbitrage(symbol, exchanges) {
  // 監控多個交易所的同一標的
  // 計算實時價差
  // 秒速執行套利
  // 管理多個頭寸同步
}
```
- **難度原因**：多市場實時交易、低延遲、高並發
- **技術**：WebSocket、事件驅動、錯誤恢復、交易成本計算
- **時間投入**：3-5 天

#### 末日推演
```javascript
async function stressTest(portfolio) {
  // 定義 100+ 個極端場景
  // 蒙特卡洛模擬 10,000+ 路徑
  // 計算 VaR 和 CVaR
  // 生成風險報告
}
```
- **難度原因**：統計學、數值計算、大規模模擬
- **技術**：數值計算庫、統計方法、數據可視化
- **時間投入**：2-3 天
