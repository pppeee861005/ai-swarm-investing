### 第一篇：蜂群覺醒 — 多股票智能監控

**故事開場**：
```
她決定不再被市場欺騙。
20 個 Agent 同時睜開眼睛，監控 20 支股票。
當某一隻股票異動時，蜂群瞬間發出警報。
Scout（偵察兵）看見了異動，Lead（指揮官）評估了風險，
Notifier（通知官）才決定你是否該拿起手機。
這就是蜂群的第一步：學會看見市場真實的聲音。
```

**核心概念**：
- 🔍 **多股票監控**：同時跟蹤多支股票的成交量、價格、漲跌幅
- 📊 **異動偵測**：識別成交量異常、價格跳空、技術面異變
- 🚨 **智能告警**：將數據轉化為可執行的信號，避免信息過載
- 🐝 **Agent 架構**：三個不同職責的 Agent 協作（偵察、分析、通知）

**技術亮點**：
```
ScoutAgent
    ↓ 監控多股票
LeadAgent
    ↓ 綜合評估
NotifierAgent
    ↓ 智能決策
用戶
```

**適合人群**：
- ✅ 量化交易新手
- ✅ 想學多 Agent 協作的開發者
- ✅ 需要實時監控的交易員

**推薦學習路徑**：

3. 運行 `npm install @ai-swarm/monitor && node examples/basic-monitor.js`（5 分鐘）

### 第二篇：三維獵殺 — AI 多維評分系統

**故事開場**：
```
一支好股票，絕不只看股價。
蜂群學會了用「三維透視」看待每支股票：
基本面維度（公司體質怎樣？），
技術面維度（市場情緒如何？），
情緒面維度（大眾是否瘋狂？）。
三維合力，才能找到真正的獵物。
這是蜂群第二步：學會深度思考。
```

**核心概念**：
- 📐 **三維評分**：基本面 × 技術面 × 情緒面
- 🧠 **AI 推理**：用 Claude API 進行多維度綜合分析
- 🎯 **量化評分**：將定性評估轉化為定量分數（0-100）
- 🔗 **決策融合**：三維得分如何協作得出最終決策

**評分維度詳解**：
```
基本面 (Fundamental)
  - 盈利能力、增長率、市淨率

技術面 (Technical)
  - 支撐阻力、均線趨勢、動量指標

情緒面 (Sentiment)
  - 市場情緒、新聞熱度、機構動向

綜合評分 = f(Fundamental, Technical, Sentiment)
```

### 第三篇：自動校準 — 投資組合再平衡

**故事開場**：
```
投資組合會漂移。
當某支股票漲了 30%，整個組合比例被打亂了。
蜂群學會了自動校準：
定期掃描各持倉，計算偏差，
如果偏離目標配置太遠，自動調整。
無需人工干預，組合永遠在正軌上。
這是蜂群第三步：學會自我修正。
```

**核心概念**：
- 📊 **目標配置**：設定理想的資產配置比例
- 📈 **動態追蹤**：實時監控當前持倉與目標的偏差
- 🔄 **自動再平衡**：當偏差超過閾值時自動調整
- 💰 **成本優化**：考慮交易成本和稅收影響的智能再平衡

**再平衡策略**：
```
目標配置：60% 股票 + 40% 債券
當前配置：70% 股票 + 30% 債券（偏差 > 10%）
   ↓
觸發再平衡
   ↓
賣出 10% 股票，買入 10% 債券
   ↓
回到目標配置 60% + 40%
```

**適合人群**：
- ✅ 資產管理者


### 第五篇：跨境狙擊 — 全球市場套利

**故事開場**：
```
同一支股票，在紐約和香港的價格不一樣。
同一種商品，在東京和新加坡的期貨價格有套利空間。
蜂群聰慧的獵手不再只盯著一個市場。
它們同時監控紐約、倫敦、香港、東京，
發現稍縱即逝的跨境套利機會，
秒速執行，收割市場的不完美。
這是蜂群第五步：學會全球思考。
```

**核心概念**：
- 🌍 **多市場監控**：同時追蹤不同交易所的同一標的物
- 📊 **實時價差計算**：計算跨交易所的價格差異
- ⚡ **低延遲交易**：快速執行套利交易以鎖定利潤
- 🔐 **多市場協調**：管理多個交易所的頭寸同步

**跨境套利機制**：
```
紐約 Apple 股票：$150.00
香港 Apple ADR：$1,180 HKD (≈ $151.00)
   ↓
發現價差機會 ($1.00)
   ↓
紐約買進，香港賣出
   ↓
等待套利窗口關閉時平倉
   ↓
鎖定利潤（考慮稅費和交易成本）
```

### 第六篇：末日推演 — 風險壓力測試

**故事開場**：
```
每個交易員都怕黑天鵝。

知道如何在極端情況下保持生存。
```

**核心概念**：
- 📉 **極端場景模擬**：模擬金融危機、市場暴跌、流動性危機等極端情況

- 🛡️ **投資組合壓力測試**：評估投資組合在壓力情況下的表現

**壓力測試流程**：
```
定義壓力場景
    ↓
模擬市場運動
    ↓
計算投資組合損失分佈
    ↓
找出極端虧損點（99% 置信度）

制定應急風控策略
```

### 第七篇：終極顧問 — 長期投資決策系統

**故事開場**：
```
如果蜂群有一個軍師呢？
一個能記住每個決策的來龍去脈，
一個能從過去的成功和失敗中學習，
一個能為你的長期目標給出個性化建議的 AI。
這不是一個交易機器人，而是一個智慧的顧問。
它用 Opus 的長期記憶和深度推理，
幫你思考：我該持有嗎？我該加倉嗎？我該止損嗎？
這是蜂群的最終進化：從執行者變成決策夥伴。
```

**核心概念**：
- 🧠 **長期上下文管理**：用 Claude Opus 的 200K Token 上下文，記住完整的投資歷史
- 📚 **決策日誌**：記錄每筆交易的原因、環境、結果，形成可查詢的決策庫
- 🎯 **個性化建議**：基於用戶的風險偏好、投資目標、過去表現給出定制化建議
- 🔄 **持續學習**：從每個交易中學習，優化策略和決策框架

**決策流程**：
```
用戶問題：「我該加倉蘋果嗎？」
    ↓
檢查完整上下文
    ├─ 過去為什麼買蘋果？
    ├─ 當前的持倉情況？
    ├─ 市場環境如何？
    ├─ 用戶的風險承受度？
    └─ 相似歷史案例的結果？
    ↓
深度推理
    ↓
個性化建議
    ↓
記錄决策 → 更新決策庫
```

## 💡 核心洞察

### 為什麼是 7 篇？

- **E01-E02**：基礎感知（看清市場）
- **E03-E04**：智能決策（思考市場）
- **E05-E06**：進階執行（駕馭市場）
- **E07**：終極目標（與市場和諧共處）

### 蜂群 = 分工合作的智慧系統

每個 Agent 各司其職：
- **Scout**：偵察手（看見異動）
- **Lead**：指揮官（做出判斷）
- **Notifier**：通知官（傳達信息）
- **Analyst**：分析師（深度評估）
- **Executor**：執行官（付諸行動）
- **Monitor**：監管官（風險控制）
