# AI Swarm Investing

> **「她用 20 個 Agent，征服了市場。」**

---

## 🎬 故事開場

深夜，妳盯著螢幕。
前面是 20 檔股票的即時報價。
眼睛已經疼痛，但妳不想遺漏任何一個異動。

直到妳意識到：一個人的眼睛，再怎麼快也快不過市場。

所以，妳召喚了一個 AI 蜂群。

## 🎯 核心信息

### 這不是一個普通的開源項目

它是一場**故事 + 代碼 + 實踐**的融合：

- 📖 每個 workflow 都有一篇故事（Substack）
- 💻 每個故事都對應一份代碼（GitHub）
- 🎯 每份代碼都能立即使用（npm packages）

### 全球開發者友好

- 英文 README（全球）
